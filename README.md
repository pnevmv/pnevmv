### 📌 Selected projects

**[Conversational RAG](https://github.com/pnevmv/conversational-rag-research)** — MSc thesis
Conversational question answering with Retrieval-Augmented Generation over knowledge graphs, evaluated on MultiDoc2Dial. Query rewriting with dialogue history, hybrid retrieval with reranking, and cited generation; a fixed evaluation set gates every change (F1 14.1 → 28.0 out of 35.0).

**[NEXA at CheckThat! 2026](https://github.com/pnevmv/seupd2526-nexa)** — [paper](https://ceur-ws.org/Vol-4283/paper54.pdf)
Multilingual scientific source retrieval for social-media claims (EN/FR/DE): tuned BM25 (Lucene) fused with BGE-M3 dense retrieval and fine-tuned cross-encoder reranking. Test MRR@5: 0.54.

**[TEXA at GutBrainIE 2026](https://github.com/pnevmv/GB_TEXA)** — [paper](https://ceur-ws.org/Vol-4283/paper42.pdf)
Biomedical information extraction from PubMed abstracts: fine-tuned GLiNER for NER, hybrid entity linking (exact match + embedding retrieval), and document-level relation extraction with ATLOP.

**[DSBKTE at ATE-IT, EVALITA 2026](https://github.com/btakh/ATE-TEXA)** — [paper](https://aclanthology.org/2026.evalita-1.50/)
Italian automatic term extraction: token classification vs. zero-shot LLM generation.

**[PATHX](https://github.com/Graph-Databases-2025-26/PATHX)** — Graph Databases course project
LLM-driven query processing where the LLM acts as a data source (GALOIS approach), with LangChain orchestration and token accounting.

**FinTrack**
Java/Jakarta EE web application with PostgreSQL, authentication, Docker, and financial forecasting.
